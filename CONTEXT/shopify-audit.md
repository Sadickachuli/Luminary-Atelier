# Shopify audit: celebratesweetly.com

Read-only audit of Merley's Shopify admin, October 2026. Nothing was changed. This is the factual state of the store before the refresh.

## Plan and theme

- Shopify Basic, roughly $348 a year paid annually.
- Active theme: **Studio (Fall 2025 Version)**, last saved 5 December. Version 16.0.0 is available as an update. Run the update before customizing.
- Studio is a modern section-based theme, so the refresh and redesign need no custom Liquid. Sections can be added, reordered and edited in the theme editor.
- Performance is fine: LCP around 1.1 seconds, rated good. No rescue work needed.

## What the live site currently says

- Homepage headline is still **"Gifts for All Occasions"**. The repositioned homepage copy written in an earlier session was never applied.
- A teal announcement bar reads "New gifting experience begins here", and teal accents run through the site. This clashes with the warm, minimal, quiet luxury direction and needs replacing.
- Main navigation: Shop, Corporate Gifting, Custom Gifts, About Us.
- No gratitude or relationship story appears anywhere on the landing view.
